# GLOBAL MARKET V4.1 - Entête officiel sur toutes les impressions PDF

## Correction appliquée

L’entête institutionnel de l’entreprise connectée est désormais appliqué à toutes les impressions et à tous les exports PDF de GLOBAL MARKET :

- factures et reçus de vente ;
- factures groupées ;
- factures des clients sous contrat ;
- rapports généraux des ventes ;
- rapports et fiches de stock ;
- bilans journaliers ;
- liste des bilans journaliers ;
- tableau de gestion sur douze mois ;
- fiche de paiement des obligations ;
- reçu d’abonnement ;
- rapport des clients de la marketplace ;
- rapport bilan détaillé.

## Contenu dynamique de l’entête

L’entête récupère exclusivement les informations de l’entreprise liée à la session active : logo, raison sociale, forme juridique, capital social, RCCM, compte contribuable, siège social, téléphone, e-mail, activité principale, couleurs, année de gestion et exercice actif.

Le titre du bandeau est automatiquement adapté au document imprimé. Aucune information fixe de MEGA SERVICES n’est imposée lorsqu’une autre entreprise est connectée.

## Format d’impression

- A4 portrait par défaut ;
- A4 paysage uniquement pour le rapport clients prévu en paysage ;
- contenu centré dans la page ;
- entête sans débordement ;
- informations longues renvoyées proprement à la ligne ;
- tableaux conservés dans la zone imprimable ;
- pied de page et numérotation maintenus.
