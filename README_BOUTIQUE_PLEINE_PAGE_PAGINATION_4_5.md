# GLOBAL MARKET 4.5 — Boutique pleine page et pagination

Correction ciblée de l’espace Boutique officielle :

- formulaire de validation de commande défilable verticalement sur ordinateur, tablette et téléphone ;
- utilisation de la pleine largeur de l’écran ;
- grande bannière réduite d’environ 30 % ;
- affichage limité à 16 produits ou services par page ;
- boutons Précédent et Suivant selon la page ;
- pagination compatible avec la recherche, les catégories, les promotions et les nouveautés ;
- livraison et paiements de la version 4.4 conservés ;
- sécurité, stockage D1, KV et encaissement interne inchangés.
