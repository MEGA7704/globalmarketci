# Correction fiche d’inscription — version 2.4.0

La fenêtre « FICHE D’INSCRIPTION DES ENTREPRISES » a été reconstruite pour utiliser toute la largeur utile du popup, sans vide latéral et sans défilement interne sur ordinateur.

## Présentation

- cadre militaire vert sombre et doré ;
- titre et sous-titre centrés ;
- sections pleine largeur avec séparateurs dorés ;
- quatre champs d’entreprise sur une ligne ;
- deux champs de spécialité sur une ligne ;
- trois champs du responsable sur une ligne ;
- deux champs de connexion sur une ligne ;
- champs blancs et texte noir ;
- bouton de création pleine largeur, réactif et protégé contre les doubles clics.

## Sécurité

Aucune route API, liaison KV/D1, règle de session, vérification de mot de passe ou autorisation n’a été modifiée. Aucun identifiant ni mot de passe n’est documenté dans ce fichier.
