# GLOBAL MARKET V5.0 — Compte client global et panier multi-boutiques

## Corrections appliquées

- Aucun menu commun entre les profils : chaque utilisateur connecté voit uniquement le menu correspondant à son rôle, avec **Accueil**.
- Le compte client est désormais **GLOBAL MARKET** et n’est plus attaché à une boutique particulière.
- Un client connecté dispose d’un **panier unique** couvrant plusieurs boutiques.
- La validation d’une commande exige une **connexion client active**.
- Une commande multi-boutiques est automatiquement **découpée par boutique** côté serveur.
- Chaque administrateur reçoit uniquement le lot contenant les produits/services de son entreprise, avec le nom, téléphone et e-mail du client.
- Le client retrouve tous les lots de toutes les boutiques dans **Mon espace client**, avec le statut de validation/livraison de chaque lot.
- Les anciens comptes clients rattachés à une boutique sont convertis automatiquement en compte global lors d’une connexion valide.
- Pour garantir une répartition correcte entre vendeurs, les paniers multi-boutiques utilisent le **paiement à la livraison**.

## Principe

**1 client = 1 compte GLOBAL MARKET = 1 panier**, même lorsque le panier contient des articles provenant de plusieurs boutiques.
