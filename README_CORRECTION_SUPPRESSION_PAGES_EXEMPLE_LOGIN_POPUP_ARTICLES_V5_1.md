# GLOBAL MARKET V5.1 — suppression des pages héritées et catalogue cliquable

## Corrections appliquées

- Suppression de la grille d’exemples : aucun faux produit n’est injecté lorsque le catalogue réel est vide.
- Suppression de l’ancienne page de connexion plein écran : les connexions entreprise restent uniquement dans le popup de la page d’accueil.
- L’ancienne page de connexion dédiée n’existe plus : les utilisateurs passent uniquement par les popups intégrés à l’accueil.
- Les formulaires d’inscription entreprise et de mot de passe oublié sont conservés sous forme de popups, sans page de connexion séparée.
- Ajout dans les footers des liens **Conditions générales d’utilisation** et **Notre politique de confidentialité**, ouverts en popup.
- Toutes les cartes réelles de produits/services de l’accueil sont cliquables et ouvrent une fiche détaillée.
- La fiche détaillée affiche le produit/service, la boutique, la description, la catégorie, le type, la disponibilité, le prix et les boutons **Voir la boutique** / **Ajouter au panier**.
- Le panier unique client multi-boutiques et l’obligation de connexion client avant ajout/commande restent actifs.

Version : **5.1.0**
