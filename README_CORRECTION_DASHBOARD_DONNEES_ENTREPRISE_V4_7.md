# CORRECTION TABLEAU DE BORD — DONNÉES ENTREPRISE V4.7

- Suppression de tous les chiffres fictifs du tableau de bord.
- Tous les indicateurs sont calculés à partir de l’entreprise titulaire du compte connecté.
- Chiffre d’affaires, commandes, clients actifs et bénéfice : données du jour, comparées à la veille.
- Stock : quantité réelle actuelle de l’entreprise et évolution reconstruite à partir des mouvements et ventes.
- Performance : ventes réelles des 7 derniers jours.
- Répartition par catégorie : ventes réelles de l’année de gestion.
- Commandes mensuelles : ventes validées par mois pour l’année de gestion de l’entreprise.
- Activités récentes : ventes, commandes Marketplace, clients et mouvements de stock réels.
- Résumé annuel : chiffres réels de l’année de gestion avec comparaison à l’année précédente.
- Isolation stricte par companyId pour éviter tout mélange entre entreprises.
