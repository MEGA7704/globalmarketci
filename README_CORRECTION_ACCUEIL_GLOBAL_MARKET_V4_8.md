# GLOBAL MARKET V4.8 — Accueil marketplace professionnel

Cette version ajoute une vraie page d’accueil publique GLOBAL MARKET dédiée aux produits et services.

## Principales corrections

- nouvelle page d’accueil premium GLOBAL MARKET sur la route principale ;
- identité vert foncé, blanc, gris clair et accents dorés ;
- grande recherche produits / services / entreprises ;
- bouton « Créer ma boutique / se connecter » avec popup ;
- bouton « Créer un compte client / se connecter » avec popup et choix de la boutique ;
- panier général avec badge, regroupé par boutique ;
- bannière commerciale avec visuel ordinateur / smartphone / sac / carton / plante ;
- filtres par catégorie et type ;
- tri par date, prix ou nom ;
- cartes produits / services uniformes avec prix FCFA, boutique, description et actions ;
- bouton « Ajouter au panier » relié au panier public existant ;
- pagination du catalogue ;
- rendu responsive desktop, tablette et mobile ;
- exemple de vitrine automatique seulement lorsqu’aucun produit public réel n’est encore disponible ;
- la connexion entreprise conserve l’authentification sécurisée Cloudflare existante.

## Déploiement

Le projet reste compatible avec le déploiement Cloudflare Pages existant. Exécuter `npm run build` avant le déploiement.
